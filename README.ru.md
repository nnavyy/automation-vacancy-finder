# HH Job Copilot

Облачный сервис поиска вакансий и отслеживания откликов на HeadHunter (hh.ru).

- **Бесплатно:** поиск вакансий, оценка соответствия, сопроводительные письма, сохранённые вакансии, отклики, аналитика и уведомления Telegram.
- **Company Intel — $3 в месяц:** исследование компаний, контакты рекрутеров и черновики писем.

Модели ИИ и API-ключи настраиваются на сервере.

## Предпросмотр

```sh
npm install
npm run dev
```

Откройте [localhost:3000/demo](http://localhost:3000/demo), чтобы посмотреть бесплатный тариф с демонстрационными данными. Раздел Company Intel показывает экран платного доступа; аналитика остаётся бесплатной.

Онлайн-оплата пока не подключена. Доступ активируется оператором через `COMPANY_INTEL_USER_IDS`; указанная цена сама по себе не списывает деньги.
